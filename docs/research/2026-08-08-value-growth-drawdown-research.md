# 价值与成长回撤事件研究

## 研究目标

研究 `价值` 与 `成长` 两类资产在历史回撤中的共同特征，重点回答：

- 当前下跌属于普通回调，还是结构性抛售
- 下跌是否带来了估值和相对无风险利率吸引力的改善
- 历史上类似回撤之后，资产通常如何修复
- 哪些数据组合更接近“市场最悲观、但好资产没有永久变坏”的逆向窗口

本研究不直接生成买卖信号，不预测市场，也不把单一指标当成结论。

## 研究范围

### 资产簇

第一阶段只研究价值与成长，不先下钻个股：

- 价值：中证价值100、国证价值100、红利低波100
- 成长：深证成长40
- 辅助参照：沪深300、国证2000

### 数据时间

- 价格回撤研究：从各指数可用的最早 EOD 数据开始
- 多指标联合研究：统一从 `2017-12-08` 开始
- 当前最新有效交易日：`2026-08-07`
- `2026-08-08` 为周六，无新的指数收盘数据

### 数据来源

- `data/archive/index_eod/`
- `data/archive/index_valuation_percentile/`
- `data/archive/index_dividend_ratio/`
- `data/archive/bond_10y/china_10y.json`
- 估值和股债指标定义：`src/valuation/metrics.py`

## 回撤事件定义

不只统计历史最大回撤，而是把价格序列切分成可比较的回撤事件。

每个事件记录：

- 前高日期与价格
- 回撤开始日期
- 最低点日期与价格
- 最大回撤幅度
- 从前高到最低点的交易日数
- 是否已经收复前高
- 收复前高所需交易日数
- 事件期间相对其他资产簇的表现

初始分层：

- `普通回撤`：最大回撤不低于 `-5%`
- `重要回撤`：最大回撤达到 `-5%`
- `重大回撤`：最大回撤达到 `-10%`

阈值只是事件切分工具，不直接代表买入标准。

## 六类分析指标

### 1. 当前回撤级别

- 当前距历史前高的回撤
- 当前回撤在历史回撤事件中的分位
- 当前是否接近同类资产历史极端回撤区间

### 2. 回撤持续时间

- 下跌持续交易日数
- 历史同级别回撤的中位持续时间
- 当前处于回撤初期、中段还是尾段

### 3. 修复能力

- 历史收复前高的中位时间
- 1个月、3个月、6个月、12个月后的收益分布
- 未修复事件占比

### 4. 相对回撤

比较同一时间段内：

- 价值相对成长
- 价值相对沪深300
- 成长相对国证2000
- 红利低波相对价值指数

目的不是判断哪个指数“更好”，而是识别市场是否在主动抛弃某一类资产。

### 5. 估值与相对无风险利率

在回撤开始、最低点和当前点分别记录：

- PE/PB
- PE/PB历史分位
- 股息率及其历史分位
- 股债差
- 股债比

注意：当前代码里的股债差定义为：

`100 / PE - 10年期国债收益率`

它不是“股息率减国债收益率”。

### 6. 市场环境

为每个回撤事件增加环境标签：

- 价值占优 / 成长占优
- 大盘占优 / 小盘占优
- 10年国债收益率上行 / 下行
- 同步普跌 / 风格分化
- 估值压缩 / 估值扩张

环境标签用于解释事件，不能替代价格和估值数据。

## 结论分级

所有 subagent 结果必须区分：

- **事实**：直接由数据计算出的日期、幅度、分位、收益
- **统计推断**：历史相似事件的分布和中位数
- **投资解释**：对事件机制的合理解释
- **无法证明**：数据没有覆盖的因果判断

例如：

- 事实：某资产从前高回撤 `-12%`
- 统计推断：历史相似回撤后6个月收益中位数为某值
- 投资解释：这次更接近风格性抛售
- 无法证明：某个具体机构操作是直接原因

## Subagent 分工

### Agent A：价格事件提取

- 提取所有回撤事件
- 计算前高、谷底、幅度、持续时间、修复时间
- 输出结构化事件表

### Agent B：估值与股债关系

- 对齐事件日期和估值数据
- 计算 PE/PB/股息率/股债差/股债比变化
- 判断回撤是否带来相对吸引力改善

### Agent C：相对表现与市场环境

- 计算价值/成长、大盘/小盘相对表现
- 对回撤事件打环境标签
- 识别同步普跌和风格分化

### Agent D：历史相似事件与未来表现

- 按回撤幅度、持续时间、估值变化匹配历史事件
- 统计之后1/3/6/12个月收益与修复概率
- 输出样本数量和置信限制

### Agent E：数据质量审查

- 检查日期对齐、重复、缺失、异常值
- 检查不同指数可比性
- 检查样本选择偏差和指数口径变化

### 主流程：结论合成

主流程只允许基于 subagent 的结构化结果写结论，不自行补充未计算的数据。

## 第一批输出

第一阶段不做复杂模型，先产出：

1. 价值与成长回撤事件表
2. 2017-12-08 至 2026-08-07 的回撤分布
3. 每次重要回撤的估值/股债关系画像
4. 当前阶段与历史相似事件的比较
5. 对 `2026年6月`、`2026年7月`、`2026年8月初` 的事件复盘

## 当前假设

当前研究假设是：

> 逆向机会更可能出现在“价格回撤较深、估值压缩、相对无风险利率吸引力改善，但资产质量和分红条件尚未明显恶化”的事件中。

该假设必须通过历史事件统计验证，不能直接当作结论。

## 第一轮已验证结果

本节只记录已经通过实际数据统计确认的结果，不补写尚未完成的事件切分结论。

### 1. 主样本边界

价值与成长的主样本，当前只使用大陆六个指数：

- 红利低波100
- 中证价值100
- 国证价值100
- 深证成长40
- 沪深300
- 国证2000

`港股通央企红利` 与 `香港证券指数` 暂不纳入主统计样本，只能作为旁证。原因是：

- 大陆六个指数在 `2017-12-08` 到 `2026-08-07` 之间有 `2102` 个共同交易日
- 若把港股指数混入同一张统计表，共同交易日会掉到 `2043`
- 不同交易日历会直接影响回撤事件切分和修复时间统计

### 2. 当前研究的共同起点

当前研究分两层：

- 价格和回撤：可使用更长历史
- 估值、股息率、股债差、股债比联合分析：统一从 `2017-12-08` 开始

这样做的原因不是数据不足，而是：

- 中证价值100 的估值和股息数据起点较晚
- 不同指数的估值口径历史长度不一致

### 3. 2026年6月、7月、8月初的阶段复盘

#### 2026年6月

从 `2026-05-29` 到 `2026-06-30`：

- 红利低波100：`-10.18%`
- 中证价值100：`-6.70%`
- 国证价值100：`-10.58%`
- 深证成长40：`+13.84%`
- 国证2000：`+3.39%`

这段更接近：

- 价值/红利被阶段性抛弃
- 成长风格被集中追捧

#### 2026年7月

从 `2026-06-30` 到 `2026-07-31`：

- 红利低波100：`+10.96%`
- 中证价值100：`+6.66%`
- 国证价值100：`+12.29%`
- 深证成长40：`-29.62%`
- 国证2000：`-19.46%`

这说明 7 月本身不是“价值继续被抛弃”，而是一次很明显的：

- 价值/红利修复
- 成长/小盘杀估值

#### 2026年8月1日到2026年8月7日

- 红利低波100：`-3.63%`
- 中证价值100：`-0.24%`
- 国证价值100：`-2.65%`
- 深证成长40：`+9.03%`
- 国证2000：`+9.21%`

这更像是：

- 7 月修复后的短线反向波动
- 成长超跌反弹
- 尚不足以定义新的成长主导周期

### 4. 历史重要回撤后的收益分布

当前先把价值三条指数与成长一条指数合并观察。

#### `-5%` 级别事件

- 总事件数：`33`
- 回到前高比例：`87.9%`
- 修复中位交易日：`37`

谷底后收益分布：

- 1个月：`P25/P50/P75 = 5.30% / 10.28% / 12.55%`
- 3个月：`7.82% / 11.49% / 20.29%`
- 6个月：`11.90% / 18.03% / 29.07%`
- 12个月：`8.20% / 19.70% / 30.95%`

#### `-10%` 级别事件

- 总事件数：`25`
- 回到前高比例：`84.0%`
- 修复中位交易日：`53`

谷底后收益分布：

- 1个月：`P25/P50/P75 = 8.48% / 11.60% / 13.16%`
- 3个月：`10.81% / 11.98% / 22.28%`
- 6个月：`15.29% / 20.97% / 33.79%`
- 12个月：`11.83% / 22.35% / 31.51%`

当前已知的一个重要差异是：

- 价值组修复更慢
- `-5% / -10%` 事件的中位修复时间约 `44 / 93` 个交易日
- 成长组对应约 `23.5 / 42.5` 个交易日

但成长组事件数只有 `9 / 7` 个，样本偏小，不能直接下过强结论。

### 5. 回撤与估值/股债关系的联合观察

当前已确认的事实是：

- 回撤确实经常伴随相对吸引力改善
- 但改善的来源并不相同

#### 成长资产

以 `深证成长40` 的长期大回撤为例：

- 事件：`2021-02-10` 到 `2024-08-23`
- 最大回撤：`-67.0%`
- PE：`53.51 -> 17.88 -> 32.81`
- PB：`10.30 -> 3.43 -> 5.96`
- 股债差：`-1.38 -> 3.44 -> 1.34`

说明：

- 成长的底部吸引力改善，主要来自 PE/PB 压缩
- 这是典型的“估值杀到位”型改善

#### 价值资产

以 `国证价值100` 的近期回撤为例：

- 事件：`2026-03-12` 到 `2026-06-30`
- 最大回撤：`-17.1%`
- PE：`10.81 -> 9.01 -> 10.01`
- 股息率：`4.53% -> 5.68% -> 4.89%`
- 股债差：`7.45 -> 9.37 -> 8.28`

说明：

- 当前仍保留一部分回撤期改善
- 但修复后，底部优势已经回吐了一部分

#### 红利资产

以 `红利低波100` 的历史回撤为例：

- 事件：`2022-04-06` 到 `2022-10-31`
- 最大回撤：`-17.0%`
- PE：`6.12 -> 5.10 -> 8.81`
- 股息率：`4.91% -> 6.46% -> 4.45%`
- 股债差：`13.57 -> 16.95 -> 9.65`

说明：

- 红利底部的改善通常来自：
  - 股息率抬升
  - 股债差抬升
  - 股债比抬升
- 但一旦修复充分，底部优势会被明显回吐

### 6. 当前可下的结论

目前可以确认：

1. `2026年6月` 更接近价值/红利的悲观释放阶段。
2. `2026年7月` 更接近价值/红利的修复兑现阶段。
3. `2026年8月初` 更接近修复后的短线反向波动，而不是新的大级别成长主导。
4. 红利与价值的回撤机会，更常通过股息率、股债差、股债比改善体现。
5. 成长的回撤机会，更常通过 PE/PB 大幅压缩体现。

## 防误判规则

当前研究先锁定以下规则：

1. 主样本只用大陆六个指数；港股指数只做附录和旁证。
2. 同一轮下跌只能保留一个主事件，重叠事件必须合并。
3. 样本数少于 `20` 的分组，不做方向性强结论。
4. 估值与国债按事件日已知值处理；若发布时间不清晰，默认按 `T+1` 解释。
5. 文字和图表里统一使用 `earnings yield spread` 或“盈利收益率股债差”，避免误读成股息差。
6. 任何因果判断，例如具体资金行为、政策动作、机构减持，只能作为解释假设，不能当作本研究已证明事实。
