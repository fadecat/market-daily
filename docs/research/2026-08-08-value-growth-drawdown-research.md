# 价值与成长回撤事件研究

## 研究目标

研究 `价值` 与 `成长` 两类资产在历史回撤中的共同特征，重点回答：

- 当前下跌属于普通回调，还是结构性抛售
- 下跌是否带来了估值和相对无风险利率吸引力的改善
- 历史上类似回撤之后，资产通常如何修复
- 哪些数据组合更接近“市场最悲观、但好资产没有永久变坏”的逆向窗口

本研究不直接生成买卖信号，不预测市场，也不把单一指标当成结论。

## 研究范围

### 资产簇

第一阶段只研究价值与成长，不先下钻个股：

- 价值：中证价值100、国证价值100、红利低波100
- 成长：深证成长40
- 辅助参照：沪深300、国证2000

### 数据时间

- 价格回撤研究：从各指数可用的最早 EOD 数据开始
- 多指标联合研究：统一从 `2017-12-08` 开始
- 当前最新有效交易日：`2026-08-07`
- `2026-08-08` 为周六，无新的指数收盘数据

### 数据来源

- `data/archive/index_eod/`
- `data/archive/index_valuation_percentile/`
- `data/archive/index_dividend_ratio/`
- `data/archive/bond_10y/china_10y.json`
- 估值和股债指标定义：`src/valuation/metrics.py`

## 回撤事件定义

不只统计历史最大回撤，而是把价格序列切分成可比较的回撤事件。

每个事件记录：

- 前高日期与价格
- 回撤开始日期
- 最低点日期与价格
- 最大回撤幅度
- 从前高到最低点的交易日数
- 是否已经收复前高
- 收复前高所需交易日数
- 事件期间相对其他资产簇的表现

初始分层：

- `普通回撤`：最大回撤不低于 `-5%`
- `重要回撤`：最大回撤达到 `-5%`
- `重大回撤`：最大回撤达到 `-10%`

阈值只是事件切分工具，不直接代表买入标准。

## 六类分析指标

### 1. 当前回撤级别

- 当前距历史前高的回撤
- 当前回撤在历史回撤事件中的分位
- 当前是否接近同类资产历史极端回撤区间

### 2. 回撤持续时间

- 下跌持续交易日数
- 历史同级别回撤的中位持续时间
- 当前处于回撤初期、中段还是尾段

### 3. 修复能力

- 历史收复前高的中位时间
- 1个月、3个月、6个月、12个月后的收益分布
- 未修复事件占比

### 4. 相对回撤

比较同一时间段内：

- 价值相对成长
- 价值相对沪深300
- 成长相对国证2000
- 红利低波相对价值指数

目的不是判断哪个指数“更好”，而是识别市场是否在主动抛弃某一类资产。

### 5. 估值与相对无风险利率

在回撤开始、最低点和当前点分别记录：

- PE/PB
- PE/PB历史分位
- 股息率及其历史分位
- 股债差
- 股债比

注意：当前代码里的股债差定义为：

`100 / PE - 10年期国债收益率`

它不是“股息率减国债收益率”。

### 6. 市场环境

为每个回撤事件增加环境标签：

- 价值占优 / 成长占优
- 大盘占优 / 小盘占优
- 10年国债收益率上行 / 下行
- 同步普跌 / 风格分化
- 估值压缩 / 估值扩张

环境标签用于解释事件，不能替代价格和估值数据。

## 结论分级

所有 subagent 结果必须区分：

- **事实**：直接由数据计算出的日期、幅度、分位、收益
- **统计推断**：历史相似事件的分布和中位数
- **投资解释**：对事件机制的合理解释
- **无法证明**：数据没有覆盖的因果判断

例如：

- 事实：某资产从前高回撤 `-12%`
- 统计推断：历史相似回撤后6个月收益中位数为某值
- 投资解释：这次更接近风格性抛售
- 无法证明：某个具体机构操作是直接原因

## Subagent 分工

### Agent A：价格事件提取

- 提取所有回撤事件
- 计算前高、谷底、幅度、持续时间、修复时间
- 输出结构化事件表

### Agent B：估值与股债关系

- 对齐事件日期和估值数据
- 计算 PE/PB/股息率/股债差/股债比变化
- 判断回撤是否带来相对吸引力改善

### Agent C：相对表现与市场环境

- 计算价值/成长、大盘/小盘相对表现
- 对回撤事件打环境标签
- 识别同步普跌和风格分化

### Agent D：历史相似事件与未来表现

- 按回撤幅度、持续时间、估值变化匹配历史事件
- 统计之后1/3/6/12个月收益与修复概率
- 输出样本数量和置信限制

### Agent E：数据质量审查

- 检查日期对齐、重复、缺失、异常值
- 检查不同指数可比性
- 检查样本选择偏差和指数口径变化

### 主流程：结论合成

主流程只允许基于 subagent 的结构化结果写结论，不自行补充未计算的数据。

## 当前假设

当前研究假设是：

> 逆向机会更可能出现在“价格回撤较深、估值压缩、相对无风险利率吸引力改善，但资产质量和分红条件尚未明显恶化”的事件中。

该假设必须通过历史事件统计验证，不能直接当作结论。

## 第一轮已验证结果

本节只记录已经通过实际数据统计确认的结果，不补写尚未完成的事件切分结论。

### 1. 主样本边界

价值与成长的主样本，当前只使用大陆六个指数：

- 红利低波100
- 中证价值100
- 国证价值100
- 深证成长40
- 沪深300
- 国证2000

`港股通央企红利` 与 `香港证券指数` 暂不纳入主统计样本，只能作为旁证。原因是：

- 大陆六个指数在 `2017-12-08` 到 `2026-08-07` 之间有 `2102` 个共同交易日
- 若把港股指数混入同一张统计表，共同交易日会掉到 `2043`
- 不同交易日历会直接影响回撤事件切分和修复时间统计

### 2. 当前研究的共同起点

当前研究分两层：

- 价格和回撤：可使用更长历史
- 估值、股息率、股债差、股债比联合分析：统一从 `2017-12-08` 开始

这样做的原因不是数据不足，而是：

- 中证价值100 的估值和股息数据起点较晚
- 不同指数的估值口径历史长度不一致

### 3. 2026年6月、7月、8月初的阶段复盘

#### 2026年6月

从 `2026-05-29` 到 `2026-06-30`：

- 红利低波100：`-10.18%`
- 中证价值100：`-6.70%`
- 国证价值100：`-10.58%`
- 深证成长40：`+13.84%`
- 国证2000：`+3.39%`

这段更接近：

- 价值/红利被阶段性抛弃
- 成长风格被集中追捧

#### 2026年7月

从 `2026-06-30` 到 `2026-07-31`：

- 红利低波100：`+10.96%`
- 中证价值100：`+6.66%`
- 国证价值100：`+12.29%`
- 深证成长40：`-29.62%`
- 国证2000：`-19.46%`

这说明 7 月本身不是“价值继续被抛弃”，而是一次很明显的：

- 价值/红利修复
- 成长/小盘杀估值

#### 2026年8月1日到2026年8月7日

- 红利低波100：`-3.63%`
- 中证价值100：`-0.24%`
- 国证价值100：`-2.65%`
- 深证成长40：`+9.03%`
- 国证2000：`+9.21%`

这更像是：

- 7 月修复后的短线反向波动
- 成长超跌反弹
- 尚不足以定义新的成长主导周期

### 4. 历史重要回撤后的收益分布

当前先把价值三条指数与成长一条指数合并观察。

#### `-5%` 级别事件

- 总事件数：`33`
- 回到前高比例：`87.9%`
- 修复中位交易日：`37`

谷底后收益分布：

- 1个月：`P25/P50/P75 = 5.30% / 10.28% / 12.55%`
- 3个月：`7.82% / 11.49% / 20.29%`
- 6个月：`11.90% / 18.03% / 29.07%`
- 12个月：`8.20% / 19.70% / 30.95%`

#### `-10%` 级别事件

- 总事件数：`25`
- 回到前高比例：`84.0%`
- 修复中位交易日：`53`

谷底后收益分布：

- 1个月：`P25/P50/P75 = 8.48% / 11.60% / 13.16%`
- 3个月：`10.81% / 11.98% / 22.28%`
- 6个月：`15.29% / 20.97% / 33.79%`
- 12个月：`11.83% / 22.35% / 31.51%`

当前已知的一个重要差异是：

- 价值组修复更慢
- `-5% / -10%` 事件的中位修复时间约 `44 / 93` 个交易日
- 成长组对应约 `23.5 / 42.5` 个交易日

但成长组事件数只有 `9 / 7` 个，样本偏小，不能直接下过强结论。

### 5. 回撤与估值/股债关系的联合观察

当前已确认的事实是：

- 回撤确实经常伴随相对吸引力改善
- 但改善的来源并不相同

#### 成长资产

以 `深证成长40` 的长期大回撤为例：

- 事件：`2021-02-10` 到 `2024-08-23`
- 最大回撤：`-67.0%`
- PE：`53.51 -> 17.88 -> 32.81`
- PB：`10.30 -> 3.43 -> 5.96`
- 股债差：`-1.38 -> 3.44 -> 1.34`

说明：

- 成长的底部吸引力改善，主要来自 PE/PB 压缩
- 这是典型的“估值杀到位”型改善

#### 价值资产

以 `国证价值100` 的近期回撤为例：

- 事件：`2026-03-12` 到 `2026-06-30`
- 最大回撤：`-17.1%`
- PE：`10.81 -> 9.01 -> 10.01`
- 股息率：`4.53% -> 5.68% -> 4.89%`
- 股债差：`7.45 -> 9.37 -> 8.28`

说明：

- 当前仍保留一部分回撤期改善
- 但修复后，底部优势已经回吐了一部分

#### 红利资产

以 `红利低波100` 的历史回撤为例：

- 事件：`2022-04-06` 到 `2022-10-31`
- 最大回撤：`-17.0%`
- PE：`6.12 -> 5.10 -> 8.81`
- 股息率：`4.91% -> 6.46% -> 4.45%`
- 股债差：`13.57 -> 16.95 -> 9.65`

说明：

- 红利底部的改善通常来自：
  - 股息率抬升
  - 股债差抬升
  - 股债比抬升
- 但一旦修复充分，底部优势会被明显回吐

### 6. 当前可下的结论

目前可以确认：

1. `2026年6月` 更接近价值/红利的悲观释放阶段。
2. `2026年7月` 更接近价值/红利的修复兑现阶段。
3. `2026年8月初` 更接近修复后的短线反向波动，而不是新的大级别成长主导。
4. 红利与价值的回撤机会，更常通过股息率、股债差、股债比改善体现。
5. 成长的回撤机会，更常通过 PE/PB 大幅压缩体现。

## 防误判规则

当前研究先锁定以下规则：

1. 主样本只用大陆六个指数；港股指数只做附录和旁证。
2. 同一轮下跌只能保留一个主事件，重叠事件必须合并。
3. 样本数少于 `20` 的分组，不做方向性强结论。
4. 估值与国债按事件日已知值处理；若发布时间不清晰，默认按 `T+1` 解释。
5. 文字和图表里统一使用 `earnings yield spread` 或“盈利收益率股债差”，避免误读成股息差。
6. 任何因果判断，例如具体资金行为、政策动作、机构减持，只能作为解释假设，不能当作本研究已证明事实。

## 实践决策

本研究分阶段推进。

### 第一阶段：实施

先建立事实型回撤事件库，不输出买卖信号。第一阶段只回答：

- 哪类资产在什么时间发生了重要回撤；
- 回撤幅度、持续时间和相对表现如何；
- 回撤期间估值、股息率、股债差和股债比如何变化；
- 历史相似事件之后通常如何修复。

事件边界、合并规则和统计口径必须在运行统计前固定，不能根据结果事后调整。

### 第二阶段：暂缓

以下判断暂不纳入第一阶段：

- 将事件直接定义为“错杀”；
- 将资产定义为“好资产”或“应该买入”；
- 判断基本面是否没有恶化；
- 判断具体机构、政策或资金行为是否造成回撤。

这些判断需要更完整的成分股基本面、分红持续性、现金流和资金流数据。当前数据可以支持“相对吸引力是否改善”的观察，但不能单独支持上述结论。

## 当前实现口径

`2026-08-08` 的第一版实现，已经不再使用“只有收复历史原高才结束事件”的规则。

当前规则改为：

- 从阶段峰值回撤达到 `-5%` 时开始事件；
- 事件期间持续更新最低点；
- 满足以下任一条件时结束事件：
- 收复原峰值；
- 价格进入距原峰值 `3%` 以内，并连续 `10` 个交易日维持；
- 从事件低点反弹至少 `10%`，且连续 `20` 个交易日不再创新低。

这样做的原因是：

- 若只用“收复原高”作为结束条件，`沪深300` 会从 `2007-10-16` 的高点一路挂到当前；
- `国证2000` 会从 `2015-06-12` 的高点一路挂到当前；
- 中间多轮不同性质的回撤会被吞并，不适合做阶段性事件研究。

## 研究回顾：风格跷跷板

这部分记录从最初想法到当前阶段的路线，重点是 `红利低波100 (930955)` vs `深证成长40 (399326)`。

### 起点

一开始的目标不是做页面，也不是做单日涨跌解释，而是把每天沉淀的数据变成可复用的观察框架：

- 不再只看“贵不贵”
- 重点看“结构性机会在哪里”
- 先研究最鲜明、最跷跷板的对比
- 先产出 JSON，再考虑图形化

因此我们把研究收敛到一对足够鲜明的标的：

- 红利低波100
- 深证成长40

### 当前已经做到什么

现在已经有了一条稳定的数据层链路：

- 抽取历史回撤事件
- 给每个事件补上估值、股息率、10Y 国债等上下文
- 计算当前相对强弱位置
- 计算当前事件在历史中的分位
- 找历史相似事件
- 输出 `analysis-first` JSON

这意味着，当前研究已经从“能不能做”进入到“已经能持续产出结构化观察结果”。

### 当前的困惑

现在最核心的问题不是有没有数据，而是“像”到底怎么定义。

我们已经确认，简单拿“都跌了 20%”来配对是不够的，因为：

- 不同历史时期的估值中枢不同
- 不同阶段的利率环境不同
- 不同风格的回撤速度和修复速度不同

所以现在的相似度更接近：

- 同一指数内部
- 同一严重级别优先
- 在当前候选样本里的相对距离最小

这是一种“相对像”，不是跨时代的绝对像。

### 当前猜想

当前猜想是：

- 事件形态要和环境分开看
- 形态层关注回撤幅度、持续时间、修复速度
- 环境层关注 PE、股息率、10Y 国债、股债差
- 真正有意义的相似，不是单个指标像，而是“形态 + 环境”一起像

### 下一步怎么探索

接下来不先追页面，而是继续补数据层，重点做三件事：

1. 建立相对事件库
   直接研究 `930955 / 399326` 这个比值本身的极端状态。

2. 把“像”拆成可调权重
   把回撤幅度、回撤天数、估值压缩、股息率变化、利率变化分层，并给出权重。

3. 把相似事件和修复路径分开记录
   不只看历史上谁像，还要看这些相似事件后面怎么走。

如果这一步做完，后面才适合继续往结论层收敛。

## 当前方法风险与优先级调整

以下几点是在 `2026-08-09` 这一轮复盘中确认的，后续研究必须正面处理，不能默认忽略。

### 1. 相似事件匹配更适合“定位”而不是“预测”

当前匹配口径是：

- 同一指数内部
- 同一严重级别优先
- 在候选样本里取归一化距离最近的历史事件

这个约束本身是合理的，但在尾部区域会遇到结构性样本稀缺。

以 `深证成长40` 当前事件为例：

- 当前最大回撤已达到 `-31.77%`
- 在本指数历史样本中已属于较深的一档
- 最近邻事件中，不少样本的回撤深度和环境强度都明显弱于当前事件

因此，当前这套相似事件框架更适合回答：

- 当前事件在本指数历史分布里处于什么位置
- 当前事件更接近哪一类历史回撤形态

而不适合直接回答：

- 接下来大概率会怎么走

若后续要增强“预测性”用途，需要单独研究更大的尾部样本库，可能要扩展到跨指数、甚至跨市场的形态层参考，但不能和当前同指数内部比较口径混为一谈。

### 2. 回撤收益分布存在重叠样本污染风险

当前文档里已经锁定规则：

- 同一轮下跌只能保留一个主事件
- 重叠事件必须合并

但这条规则必须通过专门的数据质量审查去验证，而不能只停留在规则层面。

如果多个事件的谷底时间彼此过近，或者明显落在同一修复窗口内，那么：

- 这些事件并不是独立样本
- 谷底后 `1 / 3 / 6 / 12` 个月收益分布会出现自相关
- 分位数看起来稳定，但实际置信度会被高估

因此，Agent E 后续必须单独检查：

- 相邻事件谷底日期的间隔分布
- 事件谷底与历史修复中位时间的关系
- 是否存在大量事件间隔小于对应修复中位时间的情形

若该问题明显存在，则历史收益分布只能作为方向性描述，不能被误读为高置信度统计结论。

### 3. 风格切换烈度应作为环境标签单独建模

`2026年6月` 到 `2026年7月` 的风格反转速度非常剧烈：

- `2026年6月`：成长明显占优，价值/红利被阶段性抛弃
- `2026年7月`：价值/红利快速修复，成长/小盘明显杀估值

这种月度级别的快速切换，不应简单归入一般回撤修复，而更接近：

- 资金面集中切换
- 杠杆与情绪的放大波动
- 高烈度的风格再定价

因此，后续环境层不应只记录“价值占优 / 成长占优”，还应增加“切换烈度”维度，例如：

- 回撤事件发生前 `1-2` 个月风格相对收益的斜率
- 同窗口内相对收益的波动率
- 月度级别的风格切换幅度

否则，当前事件可能会被错误匹配到本质更平稳的历史修复案例。

### 4. 原假设当前只能验证必要条件，不能验证充分条件

当前原假设是：

> 深回撤 + 估值压缩 + 相对无风险利率改善 + 资产质量未明显恶化，更可能构成逆向机会。

但其中最后一项“资产质量未明显恶化”已经被明确划入第二阶段暂缓。

这意味着：

- 目前能验证的是前 `3` 项必要条件
- 不能验证“这次便宜是不是因为真的变差了”
- 也不能验证“均值回归是否有基本面约束”

所以，当前研究输出若用于后续任何评分或惩罚系数设计，只能解释为：

- 当前是否具备逆向窗口的必要条件

不能解释为：

- 当前已经具备足够的买入充分条件

这条边界必须在后续所有结论和模型接口中反复提醒自己。

### 5. 下一步优先级调整

此前的下一步设想是：

1. 建立相对事件库
2. 把“像”拆成可调权重
3. 把相似事件和修复路径分开记录

经过这一轮复盘后，优先级调整为：

1. 先审计事件表与历史标签本身是否可信
2. 再验证当前简化相似度框架是否真的有信息量
3. 最后才决定是否值得投入更复杂的加权距离与相对事件库

更具体地说，下一步应先做一个“简化回测”：

- 用当前最简单的匹配规则
- 在历史上逐次回看每个事件
- 检查匹配出的相似事件，对谷底后收益方向和幅度是否有任何稳定信息增量

只有在这一步证明“简单方法本身有一定信息含量”后，才有必要继续升级：

- 可调权重相似度
- 相对事件库
- 更复杂的环境分层

如果连简化方法都没有稳定信息量，那么继续精细化相似度算法的性价比会很低。

#### 当前推荐的实际执行顺序

当前推荐顺序收敛为：

1. `rebound_stability` 伪修复回溯诊断；
2. 估值分位是否存在 expanding-window 前视偏差检查；
3. 按资产机制拆分为 `红利 / 纯价值 / 成长` 三个子簇；
4. 对红利簇新增 `股息率差 = 股息率 - 10Y国债收益率` 指标；
5. 对红利簇做“股息率差分组验证”，判断该指标是否真的携带修复信息；
6. 在 `walk-forward` 规则中正式写清删失样本处理口径；
7. 完成上述检查后，再运行简化回测。

这套顺序的核心原则是：

- 先确认事件结束规则、估值标签和资产分簇是否可靠；
- 再判断简单相似度框架有没有信息量；
- 最后才讨论是否值得继续做更复杂的相似度升级。

#### 关于“同质性预检”这次为什么不作为硬前置

此前评审建议，在正式拆簇前先做一次红利/价值/成长的同质性预检，例如使用 `K-S` 或 `Mann-Whitney U` 对：

- 修复时间；
- 估值变化；
- 回撤幅度；

做显著性检验。

这个建议在方法论上成立，但当前阶段不把它作为硬前置步骤，原因是：

- 我们已经有较强的样本内证据表明三者驱动机制并不相同；
- `2026年6月` 的阶段表现已经显示出显著差异：
  - `中证价值100`：`-6.70%`
  - `红利低波100`：`-10.18%`
  - `国证价值100`：`-10.58%`
- 当前研究最确定的洞察，本身就是“红利/价值/成长的修复机制存在差异”。

因此，当前口径选择：

- 先直接拆簇；
- 拆簇后立刻做样本量审计和可信度分级；
- 若拆簇后发现样本过少或统计差异并不稳定，再回头补正式的同质性预检。

也就是说，同质性预检不是被否定，而是被降级为：

- 若拆簇后样本量或统计稳定性不足，再补做的验证步骤。

#### 简化回测的强制约束：禁止前视偏差

后续“简化回测”必须采用严格的 `walk-forward` 口径。

对于任一历史目标事件 `T`：

- 只能使用 `T` 发生日期之前已经结束的历史事件作为候选相似事件；
- 不能使用 `2026-08-09` 视角下的完整事件表做全局最近邻；
- 不能使用目标事件未来才会知道的信息，例如：
  - 最终回撤到底有多深；
  - 最终是否修复；
  - 最终修复用了多久。

简化回测的目的，是验证“在当时已知信息下，简单相似度框架是否有信息量”，而不是验证“事后看哪些事件彼此相像”。

若不满足这条约束，则回测结果默认视为存在系统性乐观偏差，不能用于判断该框架是否有效。

### 6. 重叠样本污染需要可执行判据

Agent E 不应只做定性检查，必须给出明确判据。

后续对每个严重级别分组，至少检查：

- 事件谷底日期两两间隔小于该级别修复中位时间的比例；
- 其中重点关注 `-5%` 与 `-10%` 级别事件。

建议口径为：

- 若该比例不高于 `30%`，则当前收益分布可继续作为方向性统计描述；
- 若该比例超过 `30%`，则默认存在明显重叠污染，必须进一步处理后，才能继续解释收益分布。

后续可选处理方式包括：

- 对高度重叠事件做加权合并；
- 使用 `block bootstrap` 而不是把事件直接视为独立样本；
- 至少重新报告经处理后的置信区间，而不是只给 `P25 / P50 / P75`。

在该检查完成前，当前 `33` 个 `-5%` 事件与 `25` 个 `-10%` 事件的收益分布，应视为“待审计”的初步统计，而不是最终结论。

### 7. 风格切换烈度给出可计算定义

风格切换烈度不再只做文字标签，后续直接定义为连续变量。

当前建议的第一版定义：

- 在事件起点前 `20` 个交易日窗口内，计算“价值 - 成长”相对收益的滚动斜率；
- 在事件起点前 `40` 个交易日窗口内，计算同一相对收益序列的滚动斜率；
- 进一步记录：
  - `20` 日斜率；
  - `40` 日斜率；
  - `20` 日斜率相对前一可比窗口的变化幅度；
  - `40` 日斜率相对前一可比窗口的变化幅度。

其中，“斜率变化幅度”可以理解为：

- 当前窗口斜率减去前一可比窗口斜率；
- 相当于观察“风格切换速度是否正在明显加速”。

这样做的目的，是把“风格切换烈度”从叙述性判断变成：

- 可进入相似度计算的数值特征；
- 可单独审视的环境风险变量。

### 8. V2 打分公式的传导边界：估值惩罚系数不应双向对称

由于当前研究只能验证必要条件，而不能验证充分条件，因此后续若把研究结果传导到 V2 打分公式，估值分位惩罚系数必须保持不对称。

当前建议方向是：

- 对极端高分位：惩罚可以更强；
- 对极端低分位：奖励必须保守，并设置上限。

原因是：

- 极端高分位对应的“追涨风险”主要是估值风险，本身不需要额外的质量确认；
- 极端低分位对应的“抄底机会”则正好落在必要条件与充分条件的缺口上；
- 在没有质量维度过滤前，不能默认低分位一定意味着均值回归机会。

因此，后续若设计估值分位惩罚系数，更合理的方向是：

- 把它当成“阻尼器”而不是“确认信号”；
- 尤其在低分位方向上，不应把估值便宜直接转译成强烈加分。

#### 红利簇的股息率差不能直接当作已验证机制

对红利簇补充 `股息率差` 指标，只代表它进入了候选解释变量集合，不代表已经证明它是核心修复机制。

在把该指标传导到任何评分、惩罚系数或分层逻辑前，至少要先完成一轮分组验证：

- 以事件谷底时的股息率差分位为基准；
- 划分高位组与低位组；
- 比较两组后续 `1 / 3 / 6` 个月的修复概率和收益幅度；
- 只有在差异稳定存在时，才能把“股息率差对红利修复有解释力”升级为统计支持的结论。

否则，这个指标只能被视为：

- 一个符合投资直觉的候选变量；

不能被视为：

- 已完成验证、可以直接进入 `V2` 估值逻辑的机制变量。

#### 指数修复统计不等于真实策略修复

当前事件库和收益分布都基于指数口径。

因此需要明确：

- 指数本身会定期调仓；
- 成分股会被替换；
- 指数层面的“修复”天然包含调仓带来的生存者效应；
- 真实持有原成分股的投资组合，修复路径可能更慢，也可能更差。

所以，当前所有关于“修复速度”“回到前高比例”“后续收益分布”的统计，默认只能解释为：

- 指数口径的历史行为。

不能直接等同为：

- 真实策略或持仓组合在同类回撤中的修复表现。

### 当前阶段最确定的研究价值

在上述风险全部厘清前，当前研究最稳定、最有价值的成果，不是“预测未来怎么走”，而是已经比较清楚地展示出：

- 红利/价值资产的回撤修复，更常通过股息率、股债差、股债比改善体现
- 成长资产的回撤修复，更常通过 PE/PB 压缩体现

这个差异本身，已经足够支持后续思考：

- 不同资产簇在估值惩罚系数上，是否应该使用不同的逻辑
- 同样的极端分位，是否应被赋予不同含义

这部分洞察当前比“找历史相似事件预测未来”更直接，也更值得优先沉淀。
