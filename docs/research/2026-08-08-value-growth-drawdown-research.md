# 价值与成长回撤事件研究

## 研究目标

研究 `价值` 与 `成长` 两类资产在历史回撤中的共同特征，重点回答：

- 当前下跌属于普通回调，还是结构性抛售
- 下跌是否带来了估值和相对无风险利率吸引力的改善
- 历史上类似回撤之后，资产通常如何修复
- 哪些数据组合更接近“市场最悲观、但好资产没有永久变坏”的逆向窗口

本研究不直接生成买卖信号，不预测市场，也不把单一指标当成结论。

## 研究范围

### 资产簇

第一阶段只研究价值与成长，不先下钻个股：

- 价值：中证价值100、国证价值100、红利低波100
- 成长：深证成长40
- 辅助参照：沪深300、国证2000

### 数据时间

- 价格回撤研究：从各指数可用的最早 EOD 数据开始
- 多指标联合研究：统一从 `2017-12-08` 开始
- 当前最新有效交易日：`2026-08-07`
- `2026-08-08` 为周六，无新的指数收盘数据

### 数据来源

- `data/archive/index_eod/`
- `data/archive/index_valuation_percentile/`
- `data/archive/index_dividend_ratio/`
- `data/archive/bond_10y/china_10y.json`
- 估值和股债指标定义：`src/valuation/metrics.py`

## 回撤事件定义

不只统计历史最大回撤，而是把价格序列切分成可比较的回撤事件。

每个事件记录：

- 前高日期与价格
- 回撤开始日期
- 最低点日期与价格
- 最大回撤幅度
- 从前高到最低点的交易日数
- 是否已经收复前高
- 收复前高所需交易日数
- 事件期间相对其他资产簇的表现

初始分层：

- `普通回撤`：最大回撤不低于 `-5%`
- `重要回撤`：最大回撤达到 `-5%`
- `重大回撤`：最大回撤达到 `-10%`

阈值只是事件切分工具，不直接代表买入标准。

## 六类分析指标

### 1. 当前回撤级别

- 当前距历史前高的回撤
- 当前回撤在历史回撤事件中的分位
- 当前是否接近同类资产历史极端回撤区间

### 2. 回撤持续时间

- 下跌持续交易日数
- 历史同级别回撤的中位持续时间
- 当前处于回撤初期、中段还是尾段

### 3. 修复能力

- 历史收复前高的中位时间
- 1个月、3个月、6个月、12个月后的收益分布
- 未修复事件占比

### 4. 相对回撤

比较同一时间段内：

- 价值相对成长
- 价值相对沪深300
- 成长相对国证2000
- 红利低波相对价值指数

目的不是判断哪个指数“更好”，而是识别市场是否在主动抛弃某一类资产。

### 5. 估值与相对无风险利率

在回撤开始、最低点和当前点分别记录：

- PE/PB
- PE/PB历史分位
- 股息率及其历史分位
- 股债差
- 股债比

注意：当前代码里的股债差定义为：

`100 / PE - 10年期国债收益率`

它不是“股息率减国债收益率”。

### 6. 市场环境

为每个回撤事件增加环境标签：

- 价值占优 / 成长占优
- 大盘占优 / 小盘占优
- 10年国债收益率上行 / 下行
- 同步普跌 / 风格分化
- 估值压缩 / 估值扩张

环境标签用于解释事件，不能替代价格和估值数据。

## 结论分级

所有 subagent 结果必须区分：

- **事实**：直接由数据计算出的日期、幅度、分位、收益
- **统计推断**：历史相似事件的分布和中位数
- **投资解释**：对事件机制的合理解释
- **无法证明**：数据没有覆盖的因果判断

例如：

- 事实：某资产从前高回撤 `-12%`
- 统计推断：历史相似回撤后6个月收益中位数为某值
- 投资解释：这次更接近风格性抛售
- 无法证明：某个具体机构操作是直接原因

## Subagent 分工

### Agent A：价格事件提取

- 提取所有回撤事件
- 计算前高、谷底、幅度、持续时间、修复时间
- 输出结构化事件表

### Agent B：估值与股债关系

- 对齐事件日期和估值数据
- 计算 PE/PB/股息率/股债差/股债比变化
- 判断回撤是否带来相对吸引力改善

### Agent C：相对表现与市场环境

- 计算价值/成长、大盘/小盘相对表现
- 对回撤事件打环境标签
- 识别同步普跌和风格分化

### Agent D：历史相似事件与未来表现

- 按回撤幅度、持续时间、估值变化匹配历史事件
- 统计之后1/3/6/12个月收益与修复概率
- 输出样本数量和置信限制

### Agent E：数据质量审查

- 检查日期对齐、重复、缺失、异常值
- 检查不同指数可比性
- 检查样本选择偏差和指数口径变化

### 主流程：结论合成

主流程只允许基于 subagent 的结构化结果写结论，不自行补充未计算的数据。

## 第一批输出

第一阶段不做复杂模型，先产出：

1. 价值与成长回撤事件表
2. 2017-12-08 至 2026-08-07 的回撤分布
3. 每次重要回撤的估值/股债关系画像
4. 当前阶段与历史相似事件的比较
5. 对 `2026年6月`、`2026年7月`、`2026年8月初` 的事件复盘

## 当前假设

当前研究假设是：

> 逆向机会更可能出现在“价格回撤较深、估值压缩、相对无风险利率吸引力改善，但资产质量和分红条件尚未明显恶化”的事件中。

该假设必须通过历史事件统计验证，不能直接当作结论。
