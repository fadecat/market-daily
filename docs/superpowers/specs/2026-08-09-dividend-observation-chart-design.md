# 红利观察图设计说明

## 背景

本设计用于沉淀一张围绕 `930955 红利低波100` 的研究观察图。

这张图的起点，不是生成买卖信号，也不是预测市场短期涨跌，而是把当下主观的“市场感受”尽量翻译成可重复观察的数据结构。

尤其是回看 `2026年6月` 到 `2026年7月` 的红利/价值资产回撤时，核心问题不是：

- 红利会不会马上反弹；
- 现在是不是已经见底；

而是：

- 红利当前跌到了什么位置；
- 红利当前绝对定价是否已经进入低位；
- 红利相对低利率环境是否开始出现承接价值；
- 当前市场是否处于极端成长拥挤、红利被风格跷跷板压制的阶段；
- 当前价格行为只是第一次反抽，还是已经进入更可靠的修复阶段。

因此，这张图的定位必须明确：

> 它是一张 `红利观察图`，不是 `买卖图`。

## 设计目标

这张图只回答三类问题：

### 1. 价格位置

红利当前跌到什么位置，离过去一段时间的高点还有多远。

### 2. 定价与利率相对吸引力

红利当前：

- 绝对估值贵不贵；
- 相对无风险利率值不值；

这两者必须分开观察，不能混成一个“便宜”。

### 3. 风格挤压与修复状态

当前市场是否已经极端偏向成长，红利是否仍处于被挤压阶段，以及当前反弹到底属于：

- 失败修复；
- 临时修复；
- 确认修复。

## 非目标

第一版明确不做以下事情：

- 不生成买卖建议；
- 不生成交易信号；
- 不输出“未来上涨概率”；
- 不做统一 research score；
- 不混合展示多个资产簇；
- 不把指数修复等同于真实投资组合修复；
- 不试图证明某类资金行为动机。

## 标的范围

第一版只做单标的观察图：

- `930955 红利低波100`

原因：

- 它最贴近当前讨论的“红利高股息低波资产”；
- 当前已有较完整的价格、估值、股息率、国债收益率和事件状态数据；
- 它能较好承接“成长拥挤后，低利率资金回流红利”的研究语境。

后续若第一版有效，再扩展到：

- `931052 中证价值100`
- `980081 国证价值100`

## 时间窗口

第一版默认窗口：

- `最近3年`

辅助切换窗口：

- `最近5年`

原因：

- `3年` 更贴近当前利率 regime 与风格环境；
- `5年` 用于校验 `3年` 窗口是否过短。

具体口径：

- 价格/回撤层：默认 `3年`，可切 `5年`
- `PE/PB` 分位：优先 `5年` 滚动分位
- `股息率差/股债差` 分位：优先 `3年` 滚动分位
- 风格层：优先 `3年` 百分位

## 图形结构

整张图共四层，使用同一时间轴。

### 第一层：价格与回撤层

字段：

- `index_close`
- `drawdown_3y_peak`
- `drawdown_5y_peak`（切换窗口时使用）

定义：

- `index_close`：红利低波100日收盘价
- `drawdown_3y_peak = close / rolling_3y_peak - 1`
- `drawdown_5y_peak = close / rolling_5y_peak - 1`

用途：

- 观察当前价格所处区间；
- 观察当前相对近 `3年/5年` 高点的回撤程度。

显示方式：

- 主线：价格
- 辅助：回撤线或回撤阴影区

### 第二层：绝对定价层

字段：

- `pe_ttm_percentile_5y`
- `pb_lf_percentile_5y`

定义：

- `pe_ttm_percentile_5y`：滚动 `5年` 的 `PE(TTM)` 百分位
- `pb_lf_percentile_5y`：滚动 `5年` 的 `PB(LF)` 百分位

用途：

- 回答红利绝对贵不贵；
- 避免只因为价格跌了，就误判“已经便宜”。

显示方式：

- 统一 `0-100` 百分位坐标；
- 参考线：`20 / 50 / 80`

解释方向：

- 百分位越低，绝对估值越便宜；
- 百分位越高，绝对估值越贵。

### 第三层：利率相对吸引力层

字段：

- `dividend_yield_spread`
- `dividend_yield_spread_percentile_3y`
- `earnings_yield_spread`
- `earnings_yield_spread_percentile_3y`

定义：

- `dividend_yield_spread = 股息率 - 10Y国债收益率`
- `dividend_yield_spread_percentile_3y`：滚动 `3年` 股息率差百分位
- `earnings_yield_spread = 100 / PE - 10Y国债收益率`
- `earnings_yield_spread_percentile_3y`：滚动 `3年` 盈利收益率股债差百分位

用途：

- 回答红利相对低利率环境是否已经出现承接价值；
- 区分“绝对不便宜，但相对债券仍有吸引力”的情况。

显示方式：

- 图上画 percentile；
- hover 同时显示原始值和 percentile；
- 第一版先不放 `股债比`，避免信息过密。

解释方向：

- 百分位越高，红利相对无风险利率越有吸引力；
- 百分位越低，相对优势越弱。

### 第四层：风格挤压层

字段：

- `style_rotation_spread`
- `style_rotation_spread_percentile_3y`

定义：

- `style_rotation_spread`：复用当前邮件体系中的 `风格轮动收益率差值`
- `style_rotation_spread_percentile_3y`：滚动 `3年` 百分位

用途：

- 观察市场是否已经极端偏向成长；
- 观察红利是否处于被风格跷跷板压制的阶段。

显示方式：

- 使用 percentile；
- 参考线：`70 / 90`

解释方向：

- 百分位越高，说明成长风格越拥挤、红利承受的挤压越强；
- 百分位越低，说明风格失衡程度较弱或正在回归。

## 状态色带

在图底部增加一条离散状态色带，字段：

- `event_state`

状态值来自：

- `event_state_model.json`

当前仅使用以下三类：

- `failed_recovery`
- `temporary_recovery`
- `confirmed_recovery`

用途：

- 避免把“利差改善”误读成“确认修复”；
- 把价格状态从定价状态里剥离出来单独观察。

颜色建议：

- `failed_recovery`：红
- `temporary_recovery`：黄
- `confirmed_recovery`：绿

## 指标方向统一

为避免视觉解释冲突，方向统一如下：

- `PE/PB percentile`：越低越偏绿，越高越偏红
- `股息率差/股债差 percentile`：越高越偏绿，越低越偏红
- `风格差值 percentile`：越高越偏橙红
- `状态色带`：红 / 黄 / 绿

## 第一版最小字段集

第一版只要求交付以下字段：

- `index_close`
- `drawdown_3y_peak`
- `pe_ttm_percentile_5y`
- `pb_lf_percentile_5y`
- `dividend_yield_spread_percentile_3y`
- `earnings_yield_spread_percentile_3y`
- `style_rotation_spread_percentile_3y`
- `event_state`

## 图的阅读顺序

推荐用户阅读顺序固定为：

1. 看风格层：市场是否已经极端偏向成长
2. 看利率层：红利相对债券是否开始有吸引力
3. 看定价层：红利绝对估值是否真的进入低位
4. 看价格与状态：当前仍是失败/临时修复，还是确认修复

## 目标输出样式

这张图最终要支持一句高度压缩的研究表达：

- 红利现在跌得深不深；
- 红利现在绝对贵不贵；
- 红利现在相对债券值不值；
- 市场现在是不是极端压制红利；
- 当前状态是不是已经进入可靠修复阶段。

## 研究边界

这张图可以支持：

- 市场状态观察；
- 风格失衡识别；
- 定价与利率相对吸引力对照；
- 修复阶段识别；

这张图不能支持：

- 直接给出买点；
- 直接给出卖点；
- 推导未来收益概率；
- 证明政策/资金行为动机；
- 证明个股投资价值。

## 后续实现原则

下一阶段实现时，优先做：

1. 数据层
2. 图形原型
3. 字段校验

在第一版图形可读之前，不增加：

- 拥挤度自制指标；
- score；
- 多资产联动；
- 自动结论生成。
