# 市场估值日报高股息去重与版式调整设计

## 目标

在 `市场估值日报` 中调整高股息区域的展示逻辑与阅读顺序：

- 以 `东财条件补充池` 为最终口径。
- `集思录高股息筛选` 中如果发现股票已出现在东财结果里，则从集思录区块剔除。
- 将页面底部两个图 `风格轮动收益率差值`、`美元人民币汇率走势` 提前到高股息区之前。

## 当前问题

### 重复标的带来理解负担

当前高股息区块里，东财补充池与集思录主表可能同时出现同一只股票。普通用户会看到两块表，但无法快速判断：

- 哪一块才是最终口径
- 为什么同一只股票重复出现
- 集思录这块到底是在补充，还是在重复展示

### 阅读路径不顺

当前预览页实际顺序为：

`估值核心 -> 高股息区 -> 果仁行业估值 -> 风格轮动收益率差值 -> 美元人民币汇率走势`

两个图被压在页面很后面，属于“上下文信息”，但出现在“股票池明细”之后，阅读上比较跳。

## 采用方案

采用方案 2：

`估值核心 -> 风格轮动收益率差值 -> 美元人民币汇率走势 -> 东财条件补充池 -> 集思录高股息筛选(去重后) -> 果仁行业估值`

## 逻辑设计

### 东财优先

- 东财补充池保持原有过滤和排序逻辑。
- 东财区块继续完整展示，不受集思录影响。

### 集思录去重

- 去重键使用 `stock_id / 证券代码`。
- 如果集思录某行的股票代码已经出现在东财补充池结果中，则该行不再展示在集思录区块。
- 去重只影响展示，不回写或修改抓取源数据。

### 文案策略

保持简洁，但让用户能看懂发生了什么：

- 标题继续保留 `集思录返回 X 只`
- 如果存在本地筛选和东财去重，则补一行：
  `筛选后 X 只，去重东财后剩余 Y 只`
- 如果去重后没有新增标的，则展示：
  `去重东财后无新增标的`

这样用户能知道：

- 集思录抓到了多少
- 本地规则筛掉了多少
- 东财已经覆盖后，集思录还能补充多少

## 代码落点

### `src/valuation/run.py`

- 调整 `_build_extra_sections()` 的区块顺序。

### `src/valuation/dividend/render.py`

- 从 `email_supplement` 读取东财代码集合。
- 在渲染集思录主表前做去重。
- 调整主表提示文案与空状态文案。

### `src/valuation/dividend/supplement.py`

- 在东财补充池组装结果中暴露稳定的股票代码集合，供渲染层去重使用。

## 测试要求

- 补充池返回的代码集合正确。
- 集思录与东财代码重叠时，集思录区块会剔除重复行。
- 去重后文案正确。
- 去重后为空时展示“无新增标的”而不是泛化空提示。
- `市场估值日报` 的 extra section 顺序更新为新顺序。

## 预研记录

方案 3 暂不落地，但记录为后续预研方向：

- 将东财与集思录合并为一张“最终池”
- 每行增加来源标记，例如 `东财`、`集思录补充`
- 需要额外设计来源优先级、排序策略、空状态和排查路径

当前不采用方案 3 的原因：

- 会模糊数据来源边界
- 不利于用户理解“为什么这只股票出现”
- 也不利于后续排查口径差异
